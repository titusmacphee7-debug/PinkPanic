# Pink Panic — the launch roster

50 weapons, 12 classes. **Real guns underneath, silly names on top.** The
silhouette should read as the real weapon so it can be sourced and recognised;
the name is the joke.

Naming register, decided 2026-08-12: **ironic and fun to say.** Not phonetic
puns — a few survive because they are the best available version of that
specific gun, but the default is a name that is funny *because* of what the gun
does. A .50 cal called Big Boo Boo. An LMG called Chatterbox. A burst rifle
called Tick Tock.

> **The ID is the archetype, not the name.** `Rifle_M4A1`, not `Rifle_Bestie`
> and not `AssaultRifle_1`. The old IDs lied — `SniperRifle_4` was a marksman —
> and a name can change without breaking an asset folder. Asset folder name IS
> the config id (CLAUDE.md rule 4), so the id has to be the thing that never
> moves.

Ranges are quoted in studs and feet. 1 stud = 1.065 ft, derived from the
standard rig measuring 5.3187 studs at a declared 5'8" (`Systems/Scale`).

## Names that carry a design commitment

A few names are promises about the numbers, not decoration. If the stats stop
matching, the name is what's wrong:

| Name | The promise |
| --- | --- |
| **Slowpoke** | Slowest-firing marksman in the game |
| **Tick Tock** | Burst rifle — the name is the cadence |
| **Tutu** | The other burst rifle, and the sillier of the two |
| **Tiny** | The physically largest weapon in the game |
| **Big Boo Boo** | The single hardest-hitting round in the game |
| **Chatterbox** | Largest magazine of any LMG |
| **Pipsqueak 7** | Smallest, lightest SMG |
| **Bossy** | Semi-auto shotgun — fast cadence, not a one-shot |
| **Thumper 870** | Heavy pump — the two-shot at 43 ft |

## Rejected, and why

- **Anything stationery-themed.** Glitter 17 survives on its own merits; Marker,
  Sketch and Tack were built on an art direction Titus never gave.
- **Food for everything.** Six food names remain, each because it is the best
  version of that specific gun: Dessert Eagle, cAKe-47, Mac & Cheese,
  Sweet & Wesson, Jawbreaker, Shortcake.
- **Phonetic puns as the default.** Scarf-L / Scarf-H, Beret M82, Dragonfruit,
  Nougat-Nagant, Reming-tart. Clever, tiring at 50.
