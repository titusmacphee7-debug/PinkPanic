# Pink Panic Stage 1 — manifest

**50 weapons + 43 attachments.**

Every file is `.obj` with a matching `pinkpanic.mtl`. File name is
exactly the ID. Muzzle faces **−Z**, up is **+Y**, right is **+X**,
origin sits at the grip. Parts are split and named — import with
**Merge Meshes OFF** or Studio will collapse them back into one mesh.

## Import into Studio

1. **Model → Import 3D** and pick the `.obj`.
2. Turn **Merge Meshes OFF**. This is the one setting that matters —
   with it on, every named part collapses into a single mesh and the
   split is gone.
3. Colour the parts by name with `tools/ApplyPinkPalette.lua` in the
   Command Bar (**Ctrl+9**) — Studio's importer ignores `.mtl` flat
   colours, so the models arrive white until you run it.
