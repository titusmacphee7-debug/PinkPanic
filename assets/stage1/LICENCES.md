# Pink Panic — asset licences

Every asset in this delivery, its source, its licence and the exact
attribution string where one is required. Generated from the same
table that drove the downloads, so nothing can ship uncredited.

**Nothing here is CC-BY-NC, share-alike, or 'free for personal use'.**
The game can be monetised as-is. CC-BY requires a credit line and
nothing else — no revenue share, no permission to ask, no restriction
on modifying the models.

An attachment is generic by nature: there is no 'real named' vertical
grip the way there is a real named Glock. Authoring them puts the
origin exactly on the mating face, keeps the naming exactly to spec,
makes the style consistent across all 43, and adds nothing to the
credits. Say the word on any one of them and I will source a real
model instead.

## What I checked

- Every model's own name had to contain the weapon's identifying
  tokens before it could be picked, so `Pistol_Glock17` cannot
  resolve to a rifle called 'Howa Type 20' the way it did on the
  first pass.
- Every pick was then looked at in a render. Six sources were
  rejected by eye and swapped — see the table below.
- Only `downloadable=true` models under CC0 or CC-BY were considered.
  Sketchfab's own 'Free Standard' licence is not a CC licence and was
  excluded.
